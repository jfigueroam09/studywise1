# StudyWise

MVP para un Treball de Recerca sobre IA y educación.

## Publicación

El proyecto está preparado para Vercel: frontend estático en `public/` y funciones serverless en `api/`.

### Variables de entorno en Vercel

- `OPENAI_API_KEY`
- `OPENAI_MODEL`

Sin estas variables, la aplicación funciona en modo demo con un algoritmo local de priorización.

## Datos

Las tareas, exámenes, planes y registros de evaluación se guardan localmente en el navegador en este MVP. No se recopilan nombres ni correos.
